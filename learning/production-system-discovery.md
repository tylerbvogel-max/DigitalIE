# Production-system discovery pattern

Follow one job across two shifts: release, kit, start, each operation, queue, inspection/hold, rework if any, and handoff. Compare the schedule’s assumed route/time/status to actual work. Then attend the daily tier meetings and trace one red condition from first signal to closure.

Look for invisible queues, readiness checks performed from memory, shortage lists disconnected from configuration/order, aging handoff issues, constraint starvation/blockage, heroics rewarded as normal performance, and measures that report too late to control the day.
