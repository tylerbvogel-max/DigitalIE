# Contribution lifecycle

## Route

`draft → review → accepted baseline/adopted practice or rejected → periodic review → superseded/retired`

## Required review questions

1. What operational decision changes because this exists?
2. What trigger, evidence, authority boundary, output, and exit condition does it define?
3. Is the source class and applicable scope explicit?
4. Does it duplicate or conflict with existing guidance?
5. Is the language generic, sanitized, and free of implied local authority?
6. How will a process agent fail safely when required information is absent?
7. What synthetic case demonstrates correct and incorrect use?

Material changes receive a rationale and supersession link. Do not silently rewrite a decision rule in place.
