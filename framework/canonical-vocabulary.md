# Canonical vocabulary

| Object | Stable meaning |
|---|---|
| Commitment | Authorized promise of scope, quantity, cost, or date |
| Work item | Bounded unit of planned or executing work |
| Product/configuration | Identified article and the effective definition governing it |
| Requirement | Verifiable obligation from an authoritative source |
| Evidence | Attributable source material preserved without asserting its meaning |
| Observation | Statement of what a person or instrument detected |
| Exception | Departure, uncertainty, or abnormal condition requiring control |
| Change | Proposed or approved alteration with defined effectivity |
| Asset | Tool, equipment, software, facility, or resource enabling production |
| Decision | Authorized selection among alternatives with recorded basis |
| Action | Owned work intended to change a condition |
| Outcome | Measured result after action or decision |

Do not use `issue`, `problem`, `root cause`, `approved`, `released`, or `complete` without the state and authority that make the term true.
