# Value-stream map

Map the delivery of value: trigger, each process step, queue/wait, handoff, rework loop, information flow, touch time, lead time, and inventory/WIP. Mark measured values separately from estimates.

Calculate total lead/touch time, \(PCE=TouchTime/LeadTime\), stable-boundary Little's Law \(WIP=ThroughputRate\times LeadTime\), and \(RTY=\prod FPY_j\). Preserve common units, boundary, rework convention, and stability assumptions. Use this for flow and delay, not root-cause proof. See [the full playbook](../playbooks/industrial-engineering/06-value-stream-map.md).
