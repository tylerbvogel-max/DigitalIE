# Interface management

**Use when:** a handoff or boundary between products, systems, organizations, suppliers, data, tooling, or facilities is failing or changing.

**Do:** name provider/receiver, controlled payload, units/format/tolerance, timing, configuration, acceptance, monitoring, ownership, and change path; test missing/stale/conflicting conditions.

**Stop when:** either side lacks authority, the interface requirement conflicts, or integrated verification is incomplete.

**Output:** interface contract, verification evidence, failure reactions, and open decisions.
