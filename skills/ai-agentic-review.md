# Agentic code review

**Use when:** code or configuration was produced or materially changed by an agent.

**Do:** inspect diff and affected behavior; trace callers, data, permissions, deployment, rollback, and operations; reproduce defects; run decisive tests; add regression fixtures; independently verify final state.

**Stop when:** intent, authority, environment, or untested high-risk behavior is unclear.

**Output:** evidence-ranked findings, reproduction, required fix, verification receipts, and residual risk.
