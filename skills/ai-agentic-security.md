# Agentic security

**Use when:** an agent consumes untrusted context, receives tools/credentials, crosses trust boundaries, or can create side effects.

**Do:** threat-model influence and action surfaces; enforce least privilege, scoped credentials, sandboxing, provenance, deterministic validation, human gates, audit, kill/revoke/rollback, and abuse evaluations.

**Stop when:** destructive authority, secret/control-data exposure, token passthrough, or unbounded execution is possible.

**Output:** threat model, capability matrix, controls, abuse fixtures, monitoring, incident path, and residual-risk decision.
