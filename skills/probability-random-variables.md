# Probability and random variables

**Use when:** a decision requires probability of events/counts/continuous outcomes or a sampling-distribution model.

**Do:** define event and exposure; justify independence, replacement, and distribution; use complement/conditional/Bayes rules as applicable; calculate expectation/variance; select Bernoulli, binomial, hypergeometric, Poisson, normal, or another justified model; use \(Z=(X-\mu)/\sigma\) and CLT only under stated conditions.

**Stop when:** the probability parameter, exposure, dependence, mixture, or tail behavior is assumed only for convenience.

**Output:** random-variable definition, model/parameters, exact equation/substitution/result, sensitivity, assumptions, and operational meaning. See [the probability playbook](../playbooks/industrial-engineering/16-probability-and-random-variables.md).
