# OEE and loss tree

**Use when:** a bounded asset/cell needs a consistent decomposition of planned production loss.

**Do:** define calendar and loss rules; calculate \(A=RunTime/PlannedTime\), \(P=IdealCycle\times TotalCount/RunTime\), \(Q=GoodCount/TotalCount\), and \(OEE=A\times P\times Q\); reconcile components to minutes and lost good units; stratify the governing loss branch.

**Stop when:** boundaries, ideal rate, quality/rework, planned downtime, or microstop definitions are inconsistent—or the asset is not relevant to the system constraint.

**Output:** components, exact inputs/equations, reconciliation, loss tree, selected mechanism, and next test. See [the playbook](../playbooks/industrial-engineering/12-oee-and-loss-trees.md).
