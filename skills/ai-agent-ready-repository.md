# Agent-ready repository

**Use when:** an agent must safely understand, change, test, or operate a codebase.

**Do:** establish C4/static, behavioral, runtime, ownership, ADR, fitness, and delivery-flow views; make setup/tests/config/generated artifacts discoverable; narrow modules and permissions; provide representative fixtures.

**Stop when:** hidden production dependencies, credentials, ownership, or verification paths prevent a safe change.

**Output:** repository contract, architecture manifest, instruction hierarchy, change/test map, and conformance checks.
