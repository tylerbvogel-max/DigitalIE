# Configuration control

**Use when:** product definition, revision, effectivity, cut-in, or as-built consistency is uncertain.

**Do:** identify baseline and configuration items; map as-designed/as-planned/as-built/as-operated states; trace proposed changes and implementation status; identify WIP/stock/delivered exposure.

**Stop when:** release, classification, approval, disposition, or audit conclusion requires authorized judgment.

**Output:** configuration-status map, affected scope, evidence gaps, and authority route.
