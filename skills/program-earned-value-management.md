# Program earned value management

**Use when:** a program or control account needs a reproducible view of integrated cost/schedule performance, forecast alternatives, period reconciliation, schedule execution, or labor/material cost drivers.

**Do:** lock status date, baseline version, WBS/control-account scope, units, period/cumulative basis, EV technique, and source evidence; reconcile period data; use the EVM Calculation MCP; compare management ETC with CPI/composite/recent forecasts; connect dollarized schedule indicators to IMS analysis; preserve the calculation receipt.

**Stop when:** PV, EV, AC, BAC, or ETC use different scopes/periods/baselines; EV lacks objective completion evidence; actuals are incomplete; baseline changes are unresolved; task populations are undefined; or the calculation is being treated as EVMS approval.

**Output:** raw inputs and provenance, reconciliation, named formulas, complete receipt, assumption-separated forecasts, thresholds, IMS implications, variance drivers, action owner, and authority boundary. See [the EVM playbook](../playbooks/program-management/07-earned-value-management.md).
