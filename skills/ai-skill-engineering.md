# AI skill engineering

**Use when:** repeated expert work should become a discoverable, reusable agent capability.

**Do:** define triggers/non-triggers, context, procedure, tools, boundaries, outputs, resources, stop conditions, versioning, and invocation/compliance evaluations.

**Stop when:** source authority, tool permission, or decision right is missing.

**Output:** skill package/card, fixtures, dependency map, and behavior-change rationale.
