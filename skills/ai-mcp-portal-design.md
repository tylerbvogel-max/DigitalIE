# MCP portal design

**Use when:** agents need governed access to organizational data or capabilities.

**Do:** define domain verbs, schemas, identity, provenance, scopes, side effects, idempotency, errors, audit, versioning, rate/time limits, degradation, revocation, and human gates.

**Stop when:** arbitrary system access, token passthrough, unclear data classification, or unowned mutations are proposed.

**Output:** portal manifest, authorization matrix, threat model, conformance fixtures, and operating owner.
