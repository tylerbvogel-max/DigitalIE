# AI context engineering

**Use when:** an agent is missing relevant information, drowning in context, operating long-term, or confusing instructions with evidence.

**Do:** define context layers and precedence; retrieve high-signal evidence just in time; preserve provenance/freshness; compact decisions, failures, and open state; evaluate missing/excess/conflict/injection cases.

**Stop when:** protected information, unauthorized access, or unresolved instruction authority is implicated.

**Output:** context contract, retrieval/compaction routes, token/latency budget, and evaluation results.
