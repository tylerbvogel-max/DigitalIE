# Manufacturing operating system patterns

These patterns describe how evidence becomes decisions, decisions become owned action, and action is tested for effect. They do not prescribe an employer's organization chart or meeting structure.

- [Tiered daily management](01-tiered-daily-management.md)
- [Cross-functional exception review](02-exception-and-recovery-review.md)
- [Monthly system review](03-monthly-system-review.md)
- [Benefits realization](04-benefits-realization.md)

Every forum must have a decision purpose, authoritative input, named decision rights, explicit output, aging control, and escalation route. A meeting without these is coordination overhead.
