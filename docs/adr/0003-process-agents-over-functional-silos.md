# ADR 0003: Organize future agents around processes, not departments

**Status:** Accepted

## Decision

Retain capability playbooks and functional profiles as the reference layer. Add a process plane and process-agent cards as the orchestration layer. Agents assemble evidence, run defined analysis, and prepare decisions; authorized humans retain release, disposition, compliance, change, commitment, return-to-service, and access decisions.

## Rationale

Exceptions and commitments cross Quality, Production, Materials, Reliability, Program, Aerospace, and Data boundaries. Department-shaped agents encourage local optimization and unclear handoffs. A generalist agent would blur controlled authority.

## Consequence

Every future agent must declare trigger, required records, allowed actions, specialist critics, escalation gates, output, and harm boundaries. Local role titles may vary; decision-rights requirements do not.
