# Corpus quality bar

Keep an entry only if it changes a real operational decision or provides a reusable field artifact.

- Name the trigger, record/evidence, decision owner, action, and exit condition.
- Use the terms operators and managers use; define terms that are not self-evident.
- Prefer a table, checklist, or concrete question over a broad principle.
- Remove rhetorical contrast, generic reassurance, and repeated guardrails; state the rule once where it belongs.
- Link to another playbook instead of restating its method.
- Treat local variation as evidence to investigate, not an automatic defect.
