# Technical data management

## Question answered

Can authorized users retrieve the correct, current, trustworthy technical information in time to make and execute a decision while preserving history, access, and retention controls?

## Data record

For each authoritative data product identify owner, system of record, identifier, schema/format, revision, status, applicability/effectivity, lineage, access class, retention, availability need, validation, archive, and supersession.

## Diagnostic questions

- Which source is authoritative when replicas disagree?
- Can a user distinguish draft, released, obsolete, and superseded information?
- Are transformations reproducible and are manual joins controlled?
- Is access proportionate to classification and need-to-know?
- Can required information be retrieved during an operational event or system outage?
- Are records retained long enough to reconstruct product and decision history?

## Exit

The authoritative source, state, lineage, access, availability, retention, and correction path are defined. A dashboard or AI summary never silently replaces controlled source data.
