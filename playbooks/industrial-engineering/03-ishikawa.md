# Ishikawa: organize possible contributors

## Best use

Use when a team needs to generate and organize candidate factors before deciding what to test. The fishbone is an input to investigation, not its conclusion.

## Build it

Put the observable effect at the head. Use categories that fit the work—commonly People, Machine, Method, Material, Measurement, and Environment. For each branch, ask what changed, varies, is missing, or is difficult to detect.

For each candidate, record:

- Evidence already available.
- Whether it is a cause, condition, detection weakness, or symptom.
- Expected signature if it were true.
- Ease and value of testing it.

Prioritize hypotheses with a simple ranking: impact if true × plausibility from evidence × testability. Do not rank by seniority or volume of opinion.

## Exit

Select the smallest set of tests that most efficiently separates competing explanations.
