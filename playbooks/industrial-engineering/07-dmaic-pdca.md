# DMAIC and PDCA: manage improvement as learning

## Choose the cadence

Use **PDCA** for a contained, reversible learning cycle. Use **DMAIC** for a chronic, measurable, cross-functional problem where baseline, causality, and control need greater rigor.

| Phase | Required question | Exit artifact |
|---|---|---|
| Define / Plan | What outcome and customer requirement are at risk? | Scoped problem, owner, CTQ, containment |
| Measure / Do | What actually happens and how trustworthy is the data? | Baseline, operational definitions, Gemba evidence |
| Analyze / Check | Which mechanisms best explain the gap? | Tested hypotheses, not a consensus guess |
| Improve / Act | What controlled change should alter the mechanism? | Action, prediction, implementation evidence |
| Control | Did it hold, and how will abnormality be detected and handled? | Control/reaction plan and effectiveness review |

## Anti-bureaucracy rule

Do not advance a phase because a template is filled out. Advance because the prior question is answered well enough to make the next decision safer.

## Control plan minimum

For each critical condition: what is measured, method/frequency, owner, normal limit/standard, reaction to abnormality, escalation path, and review cadence.
