# CAPA and 8D

## Question answered

Has the organization eliminated or reduced the cause of an actual/potential systemic nonconformity and proven the action works?

## Core sequence

Contain the effect; define problem and scope; preserve facts; identify and validate causal mechanism; select correction and corrective action; assess affected controls/documents/training; implement; verify effectiveness over defined exposure; and share learning proportionately.

8D supplies a useful team/reporting structure. CAPA supplies the governed lifecycle. Neither replaces disciplined evidence.

## Effectiveness is not completion

Define an outcome measure, baseline, target, review window, exposure count, owner, and recurrence signal before closure. Re-open if the action is bypassed, creates a new risk, or fails to change the predicted mechanism.

## Exit

The case contains a verified causal basis, action implementation evidence, an effectiveness result, and updates to the system that allowed recurrence.
