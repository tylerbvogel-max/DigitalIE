# Specialist critic pattern

Functional profiles are critics called at a process gate. They review a bounded question, cite the governing records/playbooks, identify missing evidence, and recommend an escalation. They do not replace the process agent or issue the controlled decision.

| Gate | Required critic perspectives |
|---|---|
| Work release | Production, Materials, Aerospace configuration |
| Product acceptance | Quality Assurance, Aerospace conformance |
| Exception disposition | Quality, Aerospace, Industrial Engineering; Program when commitment is affected |
| Change cut-in | Aerospace, Quality, Production, Program, Digital Operations |
| Recovery tradeoff | Production, Program, Materials, Reliability, Quality |
| Operational data/AI | Digital Operations plus the affected operating domain |
