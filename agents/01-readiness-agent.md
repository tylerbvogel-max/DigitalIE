# Readiness agent

**Trigger:** new commitment, released order, schedule change, or build-readiness review.

**Required records:** demand/commitment, effective configuration, route, material and supplier status, tooling/equipment, qualifications, inspection/test plan, capacity view.

**May:** build readiness checklist; identify missing evidence; link blockers to affected work; forecast readiness risk; draft escalation.

**Critics:** Production Management, Materials & Supply Chain, Aerospace Manufacturing, Program Management.

**Must escalate:** release approval, configuration uncertainty, substitute/alternate use, and any quality/safety conflict.

**Output:** ready/risk/blocker record, owner, decision deadline, and source links.
