# Candidate practices

A candidate is a proposed change to DigitalIE derived from public research, synthetic evaluation, or a sanitized observation. It has no operating authority.

Review must result in one recorded outcome:

- accept as a general clean-room baseline;
- adopt for an explicitly bounded local scope outside this repository;
- return for more evidence;
- reject with rationale; or
- supersede with a better-framed candidate.

Promotion requires the contribution review in [the governed lifecycle](../framework/contribution-lifecycle.md).
